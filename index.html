About

Who I am

I have spent more than eight years in data and analytics, across automation, quality assurance, metadata management and business strategy. I began in fraud detection, moved to demand forecasting, and now work on the definitions, pipelines and checks that let a company agree on its own numbers.

My book runs on one rule. Every program in it is executed, and its real output is printed on the page. That includes the results that undercut the chapter around them. A convolutional network that scores below the simpler model before it stays in the book. So does a transformer that loses to its predecessor.

Books

What I have written

From Absolute Zero

Data science, machine learning, and AI from no code to transformers and production

Forty-five chapters run from a first line of Python to transformers, retrieval, agents and production monitoring. The book assumes no programming, no calculus and no prior statistics.

The book and its repository do different jobs. The book teaches: the reasoning, the worked examples with their real output, and the practice at the end of every chapter. The repository is for running, practising and reusing the material, and it is corrected over time while the printed text stays stable.

Mini projects

Small tools

  • code/_greyscale_safe.py

    Figures that survive black ink

    Gives each colour its own dash pattern and hatch, so a figure stays readable when a print-on-demand service converts it to greyscale. It does nothing unless FAZ_GREYSCALE=1 is set.

  • code/ch43/serve.py

    A churn model behind an endpoint

    Under thirty lines of Flask that load a saved scikit-learn pipeline and return a churn probability for a JSON request.

  • scripts/build_practice.py

    A page builder that knows when it is stale

    Turns the question bank's TOML files into every practice page. Its --check flag exits non-zero when a page is out of date. Standard library only.

  • practice/exercises/_checklib.py

    Exercises that check themselves

    Shared helpers that run a learner's starter file, or the reference solution with --solution, against a check and report what failed.

  • tests/test_stable_sort_ties.py

    A regression test for tied scores

    Pins the fix for tied probabilities sorting differently on different machines, which had changed printed output in chapters 22 and 36.

  • scripts/verify_install.py

    An install check that names the chapter

    Checks the Python version and core packages, and says which chapter needs each optional one.
